## ADDED Requirements

### Requirement: Admin Nomenclature Flags
The system SHALL provide form fields in the admin product creation/edit interface to configure nomenclature capabilities on a product.

#### Scenario: Configuring a Product as Nomenclature
- **WHEN** admin edits the "Números 12cm" product
- **THEN** admin can check the "Es Nomenclatura" boolean flag and select a secondary product via "letter_product_id" for letter pricing
